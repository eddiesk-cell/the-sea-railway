# The Sea Railway

A procedural painterly world in the browser — the flooded railway across the sea,
the bathhouse burning on its headland, a train that comes and goes, and a white
dragon a long way up.

Nothing is downloaded. No models, no textures, no photographs. Every roof curve,
cloud, ripple and lantern is generated by code at load, and every brushstroke is
computed per pixel, every frame.

## Open it

**Just want to look at it:** double-click `The Sea Railway.html`. It is one
self-contained file — no server, no internet, no install.

**Want to change it:**

```bash
npm install && npm run dev
```

Then rebuild the standalone file with:

```bash
npm run build && cp dist/index.html "The Sea Railway.html"
```

## Controls

| | |
|---|---|
| Look around | drag |
| Move | W A S D |
| Rise / sink | space / C |
| Glide faster | shift |
| Ride the train | R |
| **Get down and walk** — the train waits for you | **G** |
| Circle this place, and stay | O |
| Next stop up the line | N |
| Back one stop | B |
| Let go, back to the cinematic | F |
| Show or hide the panel | H |
| Painterly on/off | P |
| Sound on/off | M |

Leave it alone for sixteen seconds and it takes the camera back, on a slow
four-minute pass through the world.

**Getting down.** Press **G** and the journey holds where it is and puts you on
the ground beside the track. Every country has places off the line — eighty-nine
of them, one film's worth in each — two hundred to a thousand metres either
side, behind a ridge or round a headland, where the window cannot see them. A
strip along the top shows a mark where something is and how far, and never what
it is; the ground shows you a path. The name arrives only once you are standing
in the place. You go alone, which is the point — every one of these films opens
with somebody who does not belong there yet.

Two ways to just *be* somewhere. **R** puts you in a window seat on a train that
runs the whole line by itself and turns round at the end, so it never finishes.
**O** takes wherever you are pointing, makes it home, and circles it — rising,
falling, never arriving — until you touch the controls again.

## The train

An electric railcar of the 1930s, which is what the Sea Railway is in the film —
a self-propelled carriage with a driver's cab in the front end, no locomotive
and no smoke, which is exactly why it crosses the water in silence.

What stops a carriage reading as a box, in the order it matters: the
cross-section (the body curves in at the bottom and the roof is a dome, not a
lid); the bogies (a sprung truck with axleboxes under each end, wheels that
turn with the ground); the waist beading, which gives the eye a horizontal to
read the length against; window pillars and recessed doors, so the flank has a
rhythm; and the gangways, which make it one train rather than five things
travelling in convoy.

The head is a rounded face — three windows, a lamp on the brow, a destination
board, a buffer beam and grab rails. Flat, not a bullet: a railcar has a face,
and a face is nearly upright.

## What makes it look painted

Three.js draws the geometry. It does not make it a painting — this does:

1. **Kuwahara filter.** For every pixel, four overlapping neighbourhoods are
   measured and the flattest one wins. Flat areas flatten further; edges stay
   crisp and shift toward whichever side is calmer. That is what a loaded brush
   does to a canvas. The sampling kernel is rotated by a slow noise field so the
   strokes lean and curve instead of sitting on a grid.
2. **Banded light instead of PBR.** One shared material lights everything in a
   few flat steps, the way a background painter lays down base, shadow and
   accent — with ambient tinted by each surface's own colour so reds stay red in
   shadow.
3. **The finish pass.** Ink lines pulled from the depth buffer, dithered
   posterisation, split-toning, paper tooth, vignette.

The sun, sky, clouds and haze come from one `skyColor()` function that the water
samples too — so the reflection can never disagree with the sky, and it costs
nothing.

## Layout

```
src/
  main.js                  the world assembled, the camera, the loop
  world/
    atmosphere.glsl.js     shared noise + the analytic sky
    sky.js                 the dome, and the palette for every hour
    water.js               the flooded plain
    paintMaterial.js       the one material everything solid uses
    bathhouse.js           Aburaya, built from a stack of shrinking tiers
    railway.js             the line, the platform, the train
    spirits.js             the waiting ones, lanterns, steam, the dragon, reeds
    geo.js                 curved Japanese roofs, hills, instancing
  regions/
    index.js               the running order: every country's air, in one table
    *.js                   one file per country, each a description not code
  post/
    painterly.js           Kuwahara + the finish
```

## Performance

Renders at whatever your screen is, and steps the resolution down on its own if
the frame rate drops below 40 — the brush is the expensive part, not the
polygons. Roughly 60 draw calls for the whole world.

## About this project

An unofficial, non-commercial homage to the landscapes of Studio Ghibli, made
for the love of them. No assets from the films are used or reproduced —
every roof curve, cloud, ripple, blade of grass and lantern in this repository
is generated by the code in `src/`. The places are evoked; the characters are
not modelled.

Studio Ghibli's films and characters belong to Studio Ghibli. The code here is
MIT licensed and mine to give away; the films that inspired it are not.

`ROUTE.md` has the whole line: **twenty-seven countries, one for every Ghibli
feature** — and three of them twice, because Mononoke, Howl's and Laputa each
have two landscapes that are nothing like each other. All twenty-seven are
laid. Ride it with **R** and it never finishes; press **O** anywhere and the
camera makes that place home and circles it.
